# SmartPark Database Structure
# Updated table schema for Supabase database

## 1. PARKING_AREAS Table
```sql
CREATE TABLE parking_areas (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name VARCHAR(255) NOT NULL UNIQUE,
    lat DECIMAL(10, 8) NOT NULL,
    lng DECIMAL(11, 8) NOT NULL,
    total_slots INTEGER NOT NULL DEFAULT 0,
    password VARCHAR(255) NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

## 2. SLOTS Table
```sql
CREATE TABLE slots (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    parking_area_id UUID NOT NULL REFERENCES parking_areas(id) ON DELETE CASCADE,
    slot_number INTEGER NOT NULL,
    status VARCHAR(20) NOT NULL CHECK (status IN ('free', 'occupied', 'reserved')),
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    UNIQUE(parking_area_id, slot_number)
);
```

### Notes:
- `parking_area_id`: References the parking area UUID
- `slot_number`: Slot number within that parking area (1-based indexing)
- `status`: Current status of the slot
- Composite unique constraint on (parking_area_id, slot_number)

## 3. SYSTEM_STATUS Table
```sql
CREATE TABLE system_status (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    system_id VARCHAR(255) NOT NULL UNIQUE,
    status VARCHAR(20) NOT NULL CHECK (status IN ('online', 'offline')),
    location VARCHAR(255),
    last_heartbeat TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

### Notes:
- `system_id`: Unique identifier for monitoring system (e.g., "parking_monitor_phoenix_marketcity")
- `status`: Current system status
- `location`: Human-readable location name
- `last_heartbeat`: Last time system sent status update

## 4. USERS Table (Supabase Auth)
```sql
-- Managed by Supabase Auth, but custom profiles can be added:
CREATE TABLE user_profiles (
    id UUID PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE,
    email VARCHAR(255),
    full_name VARCHAR(255),
    role VARCHAR(50) DEFAULT 'user' CHECK (role IN ('admin', 'operator', 'user')),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

## 6. Database Indexes
```sql
-- Performance indexes
CREATE INDEX idx_slots_parking_area ON slots(parking_area_id);
CREATE INDEX idx_slots_status ON slots(status);
CREATE INDEX idx_slots_updated_at ON slots(updated_at);
CREATE INDEX idx_system_status_heartbeat ON system_status(last_heartbeat);
CREATE INDEX idx_parking_areas_name ON parking_areas(name);
```

## 7. RLS (Row Level Security) Policies
```sql
-- Enable RLS
ALTER TABLE parking_areas ENABLE ROW LEVEL SECURITY;
ALTER TABLE slots ENABLE ROW LEVEL SECURITY;
ALTER TABLE system_status ENABLE ROW LEVEL SECURITY;

-- Policies for authenticated users
CREATE POLICY "Authenticated users can view parking areas" 
    ON parking_areas FOR SELECT 
    TO authenticated 
    USING (true);

CREATE POLICY "Authenticated users can view slots" 
    ON slots FOR SELECT 
    TO authenticated 
    USING (true);

CREATE POLICY "Authenticated users can update slots" 
    ON slots FOR UPDATE 
    TO authenticated 
    USING (true);

CREATE POLICY "System can insert/update slots" 
    ON slots FOR INSERT 
    TO authenticated 
    WITH CHECK (true);

CREATE POLICY "System can manage status" 
    ON system_status FOR ALL 
    TO authenticated 
    USING (true);
```

## 9. Location Authentication Flow

1. Monitor system connects to Supabase with user credentials
2. Fetches available parking_areas
3. User selects location and enters location password
4. System validates password against parking_areas.password field
5. If authenticated, system can read/update slots for that parking_area_id
6. All database operations use the authenticated area UUID

## 10. Database Triggers
```sql
-- Auto-update timestamp
CREATE OR REPLACE FUNCTION update_updated_at_column()
RETURNS TRIGGER AS $$
BEGIN
    NEW.updated_at = NOW();
    RETURN NEW;
END;
$$ language 'plpgsql';

CREATE TRIGGER update_parking_areas_updated_at 
    BEFORE UPDATE ON parking_areas 
    FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();

CREATE TRIGGER update_slots_updated_at 
    BEFORE UPDATE ON slots 
    FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();
```
